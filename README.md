## 🚀 Deploy in 3 Simple Steps

### **Step 1: Create Free Accounts (2 min)**

**GitHub:**
- Go to [github.com/signup](https://github.com/signup)
- Create account (it's free)
- Verify email

**Vercel:**
- Go to [vercel.com/signup](https://vercel.com/signup)
- Sign up with GitHub (easiest)

### **Step 2: Upload to GitHub (5 min)**

**Option A: Via GitHub Website (Easiest)**
1. Go to [github.com/new](https://github.com/new)
2. Name: `artwork-module`
3. Make it **Public**
4. Click **Create**
5. Click **Upload files**
6. Upload the files I've provided:
   - `app/` folder
   - `package.json`
   - `next.config.js`
   - `.gitignore`

**Option B: Via Command Line (If you know Git)**
```bash
cd your-project-folder
git init
git add .
git commit -m "Artwork module mockups"
git remote add origin https://github.com/YOUR-USERNAME/artwork-module.git
git branch -M main
git push -u origin main
```

### **Step 3: Deploy to Vercel (3 min)**

1. Go to [vercel.com](https://vercel.com)
2. Click **Add New Project**
3. Click **Import Git Repository**
4. Paste: `https://github.com/YOUR-USERNAME/artwork-module`
5. Click **Continue**
6. Click **Deploy** (don't change anything)
7. **Wait 1–2 minutes**

**You're live!** 🎉

## 🆘 Common Issues (and Fixes)

| Issue | Fix |
|-------|-----|
| "Build failed" on Vercel | Check all files are in correct folders. Look at error message. |
| "Page not found" | Verify `app/layout.js` and `app/page.js` exist. |
| GitHub repo is private | Go to repo settings, make it **Public**. Vercel needs access. |
| Updates don't appear live | Clear browser cache (`Ctrl+Shift+Delete`). Wait 2 min. Refresh. |
| Can't find repo in Vercel | Make sure GitHub repo is Public. Check URL is correct. |

Your uploaded folder should look like this:

